# Employee tasks

Minhas tarefas is inserted immediately below Cobertura in the shared authenticated menu. Profiles without Cobertura receive the task link after sales. Finance users retain their existing finance/sales restriction plus the new tasks page. All active profiles have their own workspace. Administrators may assign tasks and view tasks they created/assigned; their role does not expose another person's private tasks.

Database: employee_tasks with RLS and indexes for owner/status/deadline, creator and unsent reminders. Read: assignee or creator only. Insert: self or active administrator assignment. Update: assignee or administrator creator. Authorship and identity cannot be changed, and only the administrator creator can reassign. No permanent deletion is exposed; cancellation is reversible. Optional sale links are checked against the creator's sale visibility and, for seller/partner assignees, sale ownership. Optimistic updated_at matching prevents silent overwrites across tabs.

UI: server pagination (15 tasks), title search, pending/overdue/today/upcoming/completed/cancelled filters, three summary counters, panel editing, notes, priority, optional deadline, reminder offsets/custom time, assignment and optional sale lookup under existing sales RLS. All display and deadline inputs use Brasilia time. No HTML rendering of task text. List refreshes every minute while visible, never while the editing dialog is open.

Reminders: private scheduled PostgreSQL dispatcher every minute; pending due reminders, active assignees, row locks with SKIP LOCKED, sent timestamp in same transaction as notification. Rescheduling/reopening resets the reminder. New administrator assignments also notify the assignee. Notifications use the existing bell/realtime/toast infrastructure and link to tarefas.html?task=UUID. No external messages, browser push or email. Offline reminders remain in the bell for the next login.

Verified with rolled-back database transactions: seller creation/completion/reopening; rejected unauthorized reassignment/authorship changes; privacy between sellers and administrator unrelated personal tasks; administrator assignment and employee visibility; assignment notification; reminder dispatch once and zero duplicates on repeat. Browser fixture tested creation, checkbox completion, completed filter, drawer and layout. Syntax checks passed for tasks and shared auth/notification files; security advisor reported no new task findings. No test task records persisted. Real authenticated production browser was not exercised.
